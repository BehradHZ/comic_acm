# حباب‌ها — طرح اولیه v01

پیش‌نمایش: [balloon-style-sheet.png](balloon-style-sheet.png)

چهار الگوی SVG با پس‌زمینهٔ شفاف و بدون متن:

- `speech.svg`: دیالوگ عادی، فرم بیضی و دنبالهٔ پیوسته.
- `whisper.svg`: زمزمه، فرم بیضی با دور خط‌چین.
- `shout.svg`: فریاد، لبه‌های شکسته و نوک‌تیز.
- `narration.svg`: روایت و گذر زمان، کادر مستطیلی بدون دنباله.

داخل حباب‌ها سفید گرم و خطوط تیره‌اند. بافت نقطه‌ای در محیط یا پشت حباب قرار می‌گیرد تا متن خوانا بماند. رنگ پس‌زمینهٔ کارت‌های شیت صرفاً برای نمایش است.

فونت نمونه‌های فارسی Vazirmatn است. زبان نهایی دیالوگ‌ها هنوز انتخاب نشده؛ متن روی شیت نمایشی است و در فایل‌های مستقل وجود ندارد.

برای هر دیالوگ، اندازهٔ حباب با متن تنظیم شود؛ دور متن حداقل به‌اندازهٔ ارتفاع یک سطر فاصله بماند. دنباله به سمت گوینده هدایت شود و از روی صورت‌ها یا حباب‌های دیگر عبور نکند. دنباله را جداگانه ویرایش کنید؛ برای تغییر جهت آن کل حباب همراه با متن را آینه نکنید.

`balloon-style-sheet.svg` نسخهٔ قابل‌ویرایش شیت نمونه است. این مجموعه طرح اولیه برای بررسی ظاهر حباب‌هاست.
